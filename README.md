# 사주풀이

생년월일시로 사주팔자를 계산하고, 풀이 결과가 **왜 그렇게 나왔는지**를 일반인도 이해할 수 있게 설명하는 웹사이트입니다.
빌드 과정이 없는 정적 사이트이며, 모든 계산은 브라우저 안에서 이루어집니다(입력 정보는 서버로 전송되지 않음).

## 실행

```bash
npm install      # lunar-javascript (테스트용. 브라우저는 CDN에서 불러옴)
npm start        # http://localhost:8000 에서 확인
npm test         # 계산 엔진 + 풀이 검증
```

`index.html`을 파일로 바로 열어도 동작하지만, 로컬 서버로 여는 것을 권장합니다.

## 화면 흐름

| 경로 | 화면 |
|---|---|
| `#/` | 운세 선택 (사주팔자 종합풀이, 성격·성향, 인생 흐름·과거와 미래, 오늘의 운세, 신년운세, 대운, 궁합·상대 비교, 기초 배우기) |
| `#/input/:menu` | 개인정보 입력 (궁합은 나 + 상대 1~2명). 제출하면 여덟 글자가 떠오르는 분석 애니메이션 후 결과로 이동 |
| `#/result/:menu` | 분석 결과 |
| `#/learn` | 사주 기초 배우기 (오행 상생상극도, 천간·십성 표, 용어 사전) |

풀이 섹션마다 **"왜 이렇게 풀이되나요?"** 펼침에 계산 근거가 나오고, 본문 속 용어(밑줄)를 누르면 설명 창이 뜹니다.

### 연애·배우자 분석 기준
- 배우자 별(남성 재성, 여성 관성): 존재·뿌리·숨음, 과다, 정·편 혼잡, 용신 여부, 자리(일지 +), 합거·쟁합, 공망
- 배우자궁(일지): 오행의 길흉, 12운성, 다른 기둥과의 충·형·원진·합
- 방해 구조: 남성 군겁쟁재·재다신약, 여성 상관견관·식상 과다·비겁 과다
- 결혼 신살: 홍란·천희(+), 고신·과숙·음양차착·고란·간여지동(−)
- 배우자운 지수 = 60 + 요인 가중치 합 × 6
- 인연의 해: 배우자 별 유입(천간 정 25·편 18 / 지지 정 20·편 14), 배우자궁 육합 18·삼합 10·충 6, 홍란 12·천희 8·도화 6, 대운의 배우자 별 8, 그해 전체 운 보정

## 인생 흐름 · 궁합 계산

- 해마다 점수 = 세운 점수 × 0.6 + 대운 점수 × 0.4, 일지·월지 충 −5, 세운·대운 충 −4, 삼재 −2~3
- 힘든 시기 = 평생 점수 하위 20%(최대 50점), 잘 풀리는 시기 = 상위 20%(최소 62점), 연속된 해를 하나의 시기로 묶고 그 시기에 많이 들어온 십성으로 성격을 설명
- 궁합 8개 항목(가중치): 성격 20, 결혼 생활(배우자궁) 18, 오행 보완 15, 배우자 별 12(상대 일간이 내게 정이면 +22, 편이면 +12, 내 배우자궁과 같은 기운 +6), 대화·소통 10, 돈·가치관 10, 생활 리듬 8, 띠·집안 7
- 함께하는 시기: 두 사람의 앞으로 6년 운 점수를 각자 계산해 겹쳐 함께 좋은 해·조심할 해·결혼하기 좋은 해를 고름

## 사주 Q&A

모든 결과 화면 맨 끝의 "풀이를 보고 궁금한 게 있나요?" 칸에서 묻고, 답은 그 자리에 이어서 보여 줍니다. 대화는 같은 사람·같은 해석 방법일 때 다른 결과 화면으로 옮겨 가도 이어집니다.

`SajuQA.answer(s, question, { partners, now })`
- 질문에서 주제(결혼·연애·어울리는 상대·궁합·사업·직장·재물·시험·건강·이사·자녀·인간관계·성격·행운·대운·해석 방법·오늘·힘든/좋은 시기·달·한 해)와 시점(연도, 올해/내년/작년, N살, N년 후, N월, 이번 달)과 형태(언제? / 해도 될까? / 과거)를 읽습니다.
- 주제마다 관련 십성(예: 직장=관성·식상, 재물=재성, 연애=남성 재성·여성 관성)이 그해 들어오는지, 그 기운이 용신·희신인지, 충·합·역마·도화가 있는지로 해마다 점수를 매겨 결론 → 근거 → 조언으로 답합니다.
- 모든 계산은 브라우저 안에서 이루어지며 외부로 전송되지 않습니다.

## 주요 API

```js
const s = analyzeSaju({
  name: '홍길동', gender: 'M',            // 'M' | 'F'
  year: 1990, month: 5, day: 15,
  hour: 10, minute: 30,                    // 모르면 hour: null
  calendar: 'solar',                       // 'solar' | 'lunar' (+ isLeapMonth)
  timeMode: 'solar',                       // 'solar'(경도 보정) | 'standard'(서머타임만 제거) | 'clock'
  longitude: 127.0,                        // 출생지 경도
  ziHour: 'next',                          // 'next'(23시부터 다음 날) | 'split'(야자시)
});

Interpret.readFullSaju(s);                 // 종합풀이 { summary, sections[] }
Interpret.readToday(s, new Date());        // 오늘의 운세
Interpret.readYear(s, 2026);               // 신년운세 + 월별
Interpret.readDaeun(s);                    // 대운 흐름
Interpret.readPersona(s);                  // 성격·성향: 유형 이름, 성향 지표 4개, 일·친구·연애·가치관·스트레스
Interpret.readCompat(s, other);            // 궁합: 8개 항목 점수 + 관계·연애·생활·다툼·보완·시기·조언 풀이
Interpret.readLifeFlow(s);                 // 인생 흐름: 해마다 점수, 지나온·앞으로의 힘든/좋은 시기, 최근 12개월
Methods.applyMethod(s, 'johu');            // 해석 방법 적용 (용신 교체)
Interpret.compareCompat(s, b1, b2);        // 두 상대 중 누가 더 잘 맞는지 비교
```

풀이 섹션은 `{ id, title, lead, paragraphs[], why[] }` 형태이며, 문장 안의 `[[용어]]`는 `Interpret.GLOSSARY`의 항목을 가리킵니다.

## 계산 기준

- **연·월주**: 실제 출생 시점과 절기(입춘·경칩 …) 시각을 비교
- **일·시주**: 기본은 출생지 경도로 보정한 진태양시. 서울은 약 -32분
- **한국 시간 이력**: 1908~1911년과 1954~1961년의 UTC+8:30 시기, 1948~1951년·1955~1960년·1987~1988년 서머타임 반영
- **학파마다 다른 규칙**(필요하면 `saju.js`에서 수정)
  - 신강약 가중치: 월지 30%, 일지·시지 15%, 나머지 10%
  - 대운수: 절입일까지 일수를 3으로 나눈 뒤 반올림
  - 격국: 비겁이 투출한 경우는 제외
  - 괴강살: 무술 포함
- **용신**: 억부법을 기본으로 하고 조후를 보조로 씀. 종격은 가능성만 표시하므로 참고용

## 알려진 한계

- 음력 변환은 중국 기준 달력이라 드물게 한국 음력과 하루 차이가 날 수 있습니다.
- '해외·기타' 출생지는 경도 보정을 하지 않고, 시간대는 한국 기준으로 계산합니다. 해외 출생은 `utcOffset` 옵션으로 직접 지정해야 합니다.
- 풀이 문장은 일반적인 해석을 규칙으로 조합한 것이며, 전문 상담을 대신하지 않습니다.
