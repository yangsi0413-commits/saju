← 사주풀이로 돌아가기

개인정보 처리방침

시행일:

사주풀이(이하 "서비스")는 풀이 계산을 이용자의 기기 안에서 처리하며, 이용자가 입력 화면에서 저장에 동의한 경우에만 아래 정보를 서버에 보관합니다. 동의하지 않아도 모든 풀이를 똑같이 이용할 수 있습니다.

1. 수집 항목과 목적

항목이름(입력한 경우), 성별, 생년월일시(양력·음력, 윤달 여부), 출생지, 시간 보정·자시 설정, 선택한 해석 방법, 풀이 결과 요약(여덟 글자, 일간, 신강약, 용신, 격국, 배우자운 지수, 성향 유형), 저장 시각, 이용한 메뉴
수집하지 않는 것궁합에 입력한 상대방의 정보, 연락처, 기기 정보, IP 주소(서비스가 직접 저장하지 않음)
목적풀이 정확도 개선과 서비스 연구, 이용자의 열람·삭제 요청 처리

2. 보관 기간

저장한 날로부터 동안 보관한 뒤 삭제합니다. 이용자가 삭제를 요청하면 즉시 삭제합니다.

3. 제3자 제공과 처리 위탁

수집한 정보를 제3자에게 제공하지 않습니다. 데이터 저장을 위해 클라우드 데이터베이스 서비스(Supabase)를 이용합니다.

4. 이용자의 권리

  • 직접 삭제: 저장할 때 화면에 표시되는 삭제 코드로 내 기록 삭제 페이지에서 언제든 삭제할 수 있습니다. 같은 기기에서는 코드를 기억해 두어 버튼 하나로 삭제할 수 있습니다.
  • 열람·정정·삭제 요청: 아래 운영자 연락처로 요청할 수 있습니다.
  • 동의 거부: 저장 동의는 선택이며, 거부해도 서비스 이용에 제한이 없습니다.

5. 안전성 확보 조치

저장된 정보는 운영자로 등록된 계정만 로그인해 열람할 수 있도록 접근을 제한하며(행 단위 보안), 방문자는 정보를 저장할 수만 있고 다른 사람의 기록을 볼 수 없습니다.
